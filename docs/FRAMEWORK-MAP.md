## PERIOD decision lenses

| Value | Practical question | Do not turn it into |
| --- | --- | --- |
| Ownership | Which part is yours to decide or do? | Blame for everything that happened |
| Purpose | What direction does this choice serve? | A demand for a grand life mission |
| Resilience | What will help this choice hold under pressure? | Denial of limits or needed support |
| Integrity | Does the behavior match the standard you claim? | A purity test |
| Discipline | What structure and repeated behavior will make it real? | Punishment or raw intensity |
| Empowerment | Does this help you or someone else become more capable? | Rescue, control, or permanent dependence |

Use the six values as lenses, without scoring or averaging. A decision can involve real tradeoffs. Users explain those tradeoffs and own the choice. Control, consequences, reversibility, cost, risk, and alignment are practical supporting lenses, not additional PERIOD values.

## Rebuild sequence

Raise the standard → build the structure → repeat the action → produce the proof → rebuild self-trust → stabilize identity → reduce negotiation → own the life.

Rebuild Map makes relationships visible. Reset repairs the point where a standard and its supporting structure separated. The interface must not present the sequence as a diagnostic ladder or claim a user has attained a certified identity.

## Reinforcement boundary

The Discipline Loop connects pressure, choice, action, proof, self-trust, identity, and reduced negotiation. It explains why correction and repeated follow-through matter. It is not a points loop. An output can invite a user to notice evidence; software cannot infer self-trust or assign resilience from form answers.

## Execution boundary

Pure Execution Mode addresses hesitation around a next move. It does not replace values-based deliberation or required information. Next Move clarifies the action and its completion boundary. Do It Now reduces the distance between a known action and beginning it. Finishing the interface is not completing the action.
