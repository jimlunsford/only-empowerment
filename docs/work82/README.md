## Session and navigation contract

- URLs contain only public screen identifiers. Existing section URLs have explicit mappings and offer the original native section.
- Choices, revealed demonstrations and comparison controls live in component memory while the reader moves within the workshop. They never enter history state, URLs, storage, cookies or network requests.
- Back and Continue use native links through the existing site router. Browser Back/Forward restore the requested screen within an active session. Same-tab in-workshop navigation retains choices.
- Refresh starts a fresh session on the same address. Restart clears all workshop choices and explanations and returns to the entry; older public history entries remain usable, with no restored answers.
- Navigating to another application route unmounts the workshop and discards its state. Leaving the document for the native reading also clears state on `pagehide`, including browser back-forward-cache navigation. Returning starts with no choices.
- Choosing a different first or second independent decision clears dependent later decisions. Re-selecting the same choice leaves them intact. Reconsider explicitly clears the current decision and its dependents.
- A direct link or refresh into a later independent decision gives complete fixed facts and states that no earlier choice is available. Nothing is fabricated on the reader's behalf.
- The authored recovery branch and changed-fact scenes explicitly state their reconnection assumptions. A later scene never claims that an unsuitable earlier choice performed the missing work.
- Existing Standard Card state remains separate and follows its accepted cross-route session behavior. No confirmation-dialog implementation is changed.
